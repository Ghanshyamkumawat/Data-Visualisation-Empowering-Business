# Online Retail Power BI Dashboard

## Overview
This project presents an interactive Power BI dashboard built using an Online Retail dataset. The dashboard provides valuable insights into sales performance, customer behavior, product demand, and regional trends, helping businesses make data-driven decisions.

## Objectives
- Analyze sales performance across different regions.
- Identify top-performing products and categories.
- Understand customer purchasing behavior.
- Track revenue trends over time.
- Support strategic business decision-making through data visualization.

## Tools & Technologies
- Power BI
- Microsoft Excel / CSV Dataset
- Data Cleaning & Transformation (Power Query)
- DAX (Data Analysis Expressions)

## Dashboard Features
### 1. Revenue Analysis
- Total Revenue
- Monthly Revenue Trends
- Revenue by Country

### 2. Product Performance
- Top Selling Products
- Quantity Sold Analysis
- Product Demand Trends

### 3. Customer Insights
- Customer Purchase Patterns
- Repeat Customer Analysis
- Customer Distribution

### 4. Geographic Analysis
- Sales by Country
- Regional Performance Comparison

## Data Preparation
The following steps were performed before creating the dashboard:

1. Imported raw retail dataset.
2. Removed duplicate records.
3. Handled missing values.
4. Filtered invalid transactions.
5. Created calculated columns and measures using DAX.
6. Built relationships and optimized the data model.

## Key Insights
- Identified countries contributing the highest revenue.
- Determined best-selling products.
- Analyzed seasonal sales patterns.
- Evaluated customer purchasing behavior.
- Highlighted growth opportunities across regions.
